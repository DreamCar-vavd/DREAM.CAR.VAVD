# Готове завдання для Claude Code — сайт DREAM.CAR.VAVD

Скопіюй увесь текст нижче та встав у Claude Code.

```text
Ти — senior frontend developer і UI/UX designer. Створи повністю готовий, адаптивний, преміальний сайт для автомобільного бренду DREAM.CAR.VAVD.

ВАЖЛИВО:
1. Не вставляй готовий банер як одну картинку замість сайту.
2. Банер використовуй тільки як візуальний референс стилю, композиції, кольорів і атмосфери.
3. Логотип і фотографію автомобілів використовуй як окремі файли.
4. Усі написи, кнопки, меню, картки та секції повинні бути справжніми HTML-елементами, а не частиною картинки.
5. Не змінюй дизайн логотипа і не розтягуй зображення.
6. Не додавай вигадані рейтинги, кількість клієнтів, відгуки або нагороди.

## Технології

Створи проєкт на:
- Next.js з App Router;
- TypeScript;
- Tailwind CSS;
- next/image;
- next/font;
- Lucide React для простих функціональних іконок;
- без важких UI-бібліотек;
- без jQuery;
- без вбудованих зображень base64.

Код має бути чистим, компонентним, типізованим і готовим до production build.

## Файли зображень

Очікуй такі файли:

/public/images/reference-banner.png
/public/images/dream-car-logo.png
/public/images/hero-cars.png

Використання:
- reference-banner.png — лише як референс, не показувати на готовому сайті;
- dream-car-logo.png — логотип у шапці, hero-секції та footer;
- hero-cars.png — окрема фотографія автомобілів у головному екрані.

Якщо остаточні файли ще не додані, створи коректні placeholder-блоки з такими самими шляхами, щоб потім зображення можна було просто замінити.

## Загальна стилістика

Стиль: luxury automotive, black and gold, дорогий, стриманий, сучасний.

Основні кольори через CSS variables:
- background: #050505;
- surface: #0B0B0B;
- surface-light: #111111;
- gold: #D4AF37;
- gold-light: #F3D675;
- gold-dark: #8A6418;
- text: #F7F3EA;
- muted: #B8B0A3;
- border-gold: rgba(212, 175, 55, 0.45).

Використовуй золото як акцент, а не як суцільний фон.
Не роби сайт жовтим або помаранчевим.
Не використовуй надмірно яскраві glow-ефекти.

Шрифти:
- заголовки: Cormorant Garamond або Playfair Display;
- основний текст: Manrope або Inter;
- підключити через next/font.

## Візуальна рамка

Зроби тонку подвійну золоту рамку по периметру desktop-версії, як у референсному банері.
На мобільній версії залиш одну тонку рамку або прибери зовнішню рамку, якщо вона заважає читабельності.

- праворуч: окрема фотографія автомобілів;

- логотип не повинен бути вмонтований у фотографію.

Текст українською:

- нижче автомобілі;
```
