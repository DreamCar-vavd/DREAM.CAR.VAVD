## Ключові уточнення

- **«Статистика в панелі потребує Pro» — уточнення:**
  - **referrer** (звідки прийшли) — видно в дашборді Vercel **на Hobby**, але
    з вікном звіту **1 місяць** (історія глибше — Pro).
  - **UTM-мітки** (utm_source/medium) — розбивка **лише Pro + Web Analytics
    Plus (+$10)**.
  - **Вбудований перегляд у `/panel` через REST API** — у специфікації API є код
    відповіді `402` (Payment Required), тож **ймовірно потрібен платний тариф**;
    точно **не перевірено** (немає токена й платного акаунту для проби). Не
    прирівнювати «є Pro» до «API доступний» — це окремі речі, звіряти.
- **Два користувачі:**
  - GitHub — безкоштовно (роль collaborator Write).
  - Vercel — помічнику акаунт **не потрібен** для `/keystatic` (вхід через
    GitHub). Vercel-місце в команді потрібне лише якщо помічнику треба сам
    **дашборд Vercel** (напр. відкрити захищений Preview) — Hobby-team має
    ліміт учасників; це рішення про тариф.
- **Автоматичні нарахування:**
  - Hobby — Vercel/Neon/Blob **не донараховують**, а призупиняють ресурс при
    перевищенні.
  - Pro — донараховують за використання; є **Spend Management** (ліміт витрат +
    автопризупинення).
- **Відео й трафік — головний ризик перевищення Hobby-обсягу:** кілька
  HD-роликів огляду, які часто переглядають, можуть з'їсти ~100 ГБ трафіку/міс
  Blob. Оцінити за кількістю роликів × розміром × очікуваними переглядами перед
  створенням Blob-сховища.

## Рекомендація

Найдешевший робочий набір для **приймання на Preview** (без Production):
- GitHub App — $0;
- Neon free — $0 (заявки);
- Blob на Hobby — $0 у межах обсягу (відео);
- Web Analytics — вже є, referrer у дашборді Vercel — $0.

Рішення про **Vercel Pro** ($20/міс) — окреме: потрібне для (а) формально
коректного комерційного використання сайту, (б) UTM-розбивки трафіку,
(в) ймовірно — REST API аналітики для `/panel/traffic`, (г) довших вікон
звітів і зняття Blob-лімітів. Це рішення власника, не блокер панелі.
