`cleanupFrozenMedia` тепер **двокроковий**: сухий прогін повертає кількість +

комітить `published.json` → HEAD зсувається), підтвердження → `ConflictError`,

проти якої пораховано список. `completeDeletion` користується тим самим
захищеним пакетом з одного узгодженого знімка (`Promise.all([mediaIndex,

`already-absent` для кожного шляху; 409/422/обрив → конфлікт або transient —
**ніколи не «прибрано N»**, якщо видалення не підтверджене. Перед видаленням
показується кількість і людський розмір кандидатів (сухий прогін).

самого дерева (не проти sha-256 в імені `_pub`-файла — це інший ідентифікатор).

  містить init функції Vercel + холодні TCP до GitHub — паралелізм впливає
  слабше. Далі: кеш дерева в межах одного запиту, менше окремих `readFile`,
