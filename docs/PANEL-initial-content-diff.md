Попередня версія цього документа стверджувала, що зміна суто технічна

## Джерело, яке раніше не враховувалось: `gallery-project-overrides.json`

`src/content/gallery-project-overrides.json` (на `main`, 34 рядки) — це
**рантайм-редагований** оверлей, який читає `getDictionary()`
(`src/lib/i18n/dictionaries.ts`): для кожного `id` галерейного проєкту,
присутнього в цьому файлі, він **повністю замінює** об'єкт

через `/api/gallery-projects/[id]` — той самий маршрут, яким користується
кнопка «Редагувати інформацію» в `GalleryProjectModal.tsx` (доступна лише
в `NODE_ENV=development`, лише для `maserati-levante`/`volvo-xc60-d5`).

Станом на зараз файл містить запис лише для `maserati-levante` (uk/en/ru)
— для `volvo-xc60-d5` оверлею немає, тож для нього реально показується
базовий текст словника (включно з порожнім роком EN/RU, вище). Це
пояснює, чому порівняння «що реально бачить відвідувач» мусить враховувати
не лише `dictionaries/*.ts`, а й цей файл — інакше можна помилково
звірятися з даними, які оверлей уже переписав (для maserati-levante) або
пропустити те, що оверлею немає (для volvo-xc60-d5).
