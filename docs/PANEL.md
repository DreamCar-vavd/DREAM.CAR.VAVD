# Панель керування контентом DREAM.CAR.VAVD

Статус: **етап 1 — «Автомобілі»** з робочою моделлю чернеток і публікації
(draft PR #26, не змерджено). Повний аналіз, витрати, дії власника:
`report/34-admin-panel-stage2.md`.

---

## Дві адреси

| Адреса | Що це |
|---|---|
| **`/keystatic`** | редактор контенту (Keystatic). Тут заповнюють поля авто — назву, ціну, характеристики, фото, три мови. **Зміни тут не потрапляють на сайт.** |
| **`/panel`** | панель публікації. Тут видно стан кожного авто, тут позначають мови перевіреними й натискають «Опублікувати зміни». |

## Модель: робоча копія → перевірка → публікація

```
Keystatic (редагувати)
      │  зберігає в src/content/cms/cars/<id>.json  — РОБОЧА копія
      ▼
/panel  «Позначити перевіреним» (для кожної мови UK / EN / RU)
      │  записує src/content/cms/review-state.json
      ▼
/panel  «Опублікувати зміни»
      │  копіює робочу картку в src/content/cms/published.json — ПУБЛІЧНИЙ знімок
      ▼
Vercel збирає й деплоїть  →  зміна в ефірі за 1–3 хв
```

**Сайт читає лише `published.json`.** Тому:

- нове авто не видно на сайті, поки його не опублікують;
- редагування вже опублікованого авто **не змінює сайт** — там лишається остання опублікована версія, поки не натиснути «Опублікувати зміни»;
- незавершена чернетка ніколи не прибирає наявну картку з сайту;
- «Прибрати з сайту» і «Продано» — окремі свідомі дії (картка лишається в панелі).

## Правило трьох мов

Авто можна опублікувати лише коли для **кожної** з UK / EN / RU:

- заповнені «назва» і «характеристики», і
- натиснуто «Позначити перевіреним» у `/panel`.

**Будь-яке редагування тексту скидає перевірку цієї мови** (панель порівнює
поточний текст із тим, що було підтверджено). Зміна лише спільної ціни,
пробігу, статусу продажу чи фото — **не** скидає перевірку перекладів.

Ніякого автоперекладу немає й не буде на цьому етапі.

## Що робить `/panel` для кожного авто

- **публічний стан:** «На сайті» / «Опубліковане, приховане (продано)» / «Не опубліковане» + позначка «є неопубліковані зміни»;
- **мовні позначки:** 🔴 Не заповнено · 🟡 Потребує перевірки · 🟢 Перевірено (+ кнопка «Позначити перевіреним»);
- **список причин, що блокують публікацію** (порожні поля, непідтверджені мови, немає фото, відео у режимі «завантажений файл»);
- кнопки **«Опублікувати зміни»** (неактивна, поки є блокери або немає змін) і **«Прибрати з сайту»**.

## Відео

| Режим | Стан |
|---|---|
| Зовнішнє посилання | працює |
| Наявний локальний файл | працює (2 перенесені walkaround) |
| **Завантажений файл** | **НЕ підключено** — блокує публікацію, поки не приберете або не заміните посиланням. Потрібне зовнішнє сховище (report/34 §9). |

## Захист доступу

- `/keystatic`, `/panel`, `/api/keystatic`, `/api/panel` **повертають 404 на будь-якому деплої**, крім випадку `KEYSTATIC_STORAGE_KIND=github` (тоді вмикається вхід через GitHub).
- Локальний режим (`next dev`) — без авторизації, лише на комп'ютері розробника.
- ⚠️ **Репозиторій зараз публічний** — робочі (ще не опубліковані) тексти й фото авто **видно на GitHub** до публікації. Рекомендація: зробити репозиторій приватним (безкоштовно). Див. report/34 §7.

## Команди (розробнику; власнику не потрібні)

| Команда | Призначення |
|---|---|
| `npm run dev` → `/keystatic`, `/panel` | панель локально |
| `npm run content:check` | перевірити, що `published.json` не містить непридатних авто |
| `npm run cars:migrate` | (одноразово) перенести наявні авто — вже виконано |

## Увімкнення hosted-панелі (дії власника)

1. **GitHub App** (Settings → Developer settings → GitHub Apps → New):
   - Callback URL: `https://dream-car-vavd.com/api/keystatic/github/oauth/callback`
   - Request user authorization (OAuth) during installation: **увімкнено**; Webhook: **вимкнено**
   - Permissions → Repository: **Contents: Read and write**, **Pull requests: Read and write**, Metadata: Read; решта — **No access**
   - Install: **лише на репозиторій** `DreamCar-vavd/DREAM.CAR.VAVD`
2. Vercel → Settings → Environment Variables (Production + Preview):
   ```
   KEYSTATIC_STORAGE_KIND = github
   KEYSTATIC_GITHUB_CLIENT_ID = <App Client ID>
   KEYSTATIC_GITHUB_CLIENT_SECRET = <секрет>
   KEYSTATIC_SECRET = <випадковий рядок 32+ символів>
   ```
3. Помічник: окремий GitHub-акаунт → collaborator репозиторію з роллю **Write** (не Admin). 2FA обом.
4. Branch protection на `main`: require PR + status checks `Verify (…)` і `content:check`.
5. Застосувати діф CI з report/34 §4 (крок `content:check`).
6. **Зробити репозиторій приватним** (Settings → General → Danger Zone).

> У hosted-режимі кнопки публікації в `/panel` ще потребують окремого
> підключення (коміт через GitHub App) — report/34 §7. Локально працює повністю.
